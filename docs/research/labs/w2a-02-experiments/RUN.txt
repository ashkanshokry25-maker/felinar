w2a-02 experiments (CMS export / migration research), run 2026-10-17 on macOS 27.0 (APFS), Node 24.22.0.
Nothing here is installed into the project; the scripts import the project's own node_modules by absolute path
(create-torrent 6.1.3, webtorrent 3.0.21, bencode 4.0.1, memory-chunk-store). Run with:
  export PATH=$HOME/.local/share/node/current/bin:$PATH
  node exp_meta.mjs                 # EXP-A: .torrent size vs file count and piece length            -> results_meta.txt
  node exp_reuse.mjs                # EXP-B: piece reuse across two exports, by file ordering/padding -> results_reuse.txt
  node exp_wt_prefill.mjs           # EXP-D: real WebTorrent verifies a file-prefilled preloadedStore  -> results_wt_prefill.txt
  node exp_norm.mjs <emptydir>      # EXP-C: APFS Unicode-normalization and case behaviour            -> results_norm.txt
  node exp_url.mjs                  # EXP-E: WHATWG URL parsing of exported file names                -> results_url.txt
  node pathlint.mjs                 # reference file-name policy linter, run on exporter-style names  -> results_pathlint.txt
Synthetic data only (no site content). Pieces are SHA-1 over deterministic pseudo-random bytes.
