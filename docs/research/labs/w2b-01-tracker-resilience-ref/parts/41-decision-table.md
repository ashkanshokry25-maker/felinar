## Decision table: where does the signalling for a site come from?

Costs are list prices read on 2026-10-17 unless marked; "caps" are the numbers that bind first. Rows are not mutually exclusive: the recommended configuration combines rows 1, 2 or 6, and 7 (and uses 9 as the floor).

| # | Option | Monthly cost | What binds first | Ops burden | Independent failure domain | Main risk | Pick it when |
|---|---|---|---|---|---|---|---|
| 1 | **Public trackers** (`tracker.webtorrent.dev`, `tracker.openwebtorrent.com`, `open.ftorrent.com`, `tracker.novage.com.ua`) | $0 | nothing for us (openwebtorrent holds 288k sockets, novage 120k; webtorrent.dev 64-174k peer entries/24 h) | none | 4 operators / 4 hosts, but common DNS-category exposure | no SLA, no abuse policy, listed by DNS "piracy/torrent" lists (F2), can vanish (btorrent.xyz, fastcast.nz did) | always as extra entries, never as the only ones |
| 2 | **Own Node wrapper behind Caddy on Oracle Always Free A1** (reference deployment) | $0 (2 OCPU / 12 GB / 10 TB egress; idle-reclaim rule; stateless security-list rules; home region only) | RAM 25 KiB/socket -> 20k sockets = 0.5 GB; egress 10 TB | patch OS, Node, Caddy; unit + alerts provided | yes (own hostname, own AS) | Oracle reclaiming an "idle" instance (7 days of CPU p95 < 20% **and** network < 20% **and** memory < 20%); capacity errors at creation | you want a free, neutral-hostname tracker and accept to run a Linux box |
| 3 | **Own Node wrapper on a small VPS** (DigitalOcean $4 = 512 MiB/500 GiB, $6 = 1 GiB/1 TB; Hetzner Cloud EU plans include >= 20 TB, price not retrievable; Fly.io shared-cpu-1x $2.19 / $3.69 / $6.70 + $0.02/GB) | $2-7 (+ egress on Fly) | RAM, then egress on metered hosts | as row 2 | yes | same patching duty; Fly has no free tier and autostop must be off | Oracle capacity unavailable, or you want an SLA-backed box |
| 4 | `aquatic_ws` on a VPS | as row 3 | Linux >= 5.8, DER certs or an IP-family-preserving proxy, Rust build | higher (build, memlock, seccomp) | yes | last tag 2024-04-03; no `X-Forwarded-For` | > 20k sockets per host and you want the engine behind webtorrent.dev and ftorrent |
| 5 | `wt-tracker-rust` (Novage) | as row 3 | Rust 1.98+ toolchain; brand new | medium | yes | weeks old, no release, vendor benchmarks | > 20k sockets per host and lowest RAM; watch it for a release |
| 6 | **Cloudflare Worker + Durable Object per swarm** (prototype in `cf-do/`) | ≈ $5 up to ~2.5 M visits/month, ≈ $8.5 at 10 M, ≈ $32 at 43 M (≈ 2,000 permanent sockets) | per-swarm URL, 1,000 req/s soft limit per object | low (deploy) but code is ours | yes (different provider and AS) | deploys disconnect all sockets; lock-in; Free-plan enforcement disputed; Cloudflare sees IP/SDP | you refuse to run any server; as the *second* own tracker next to row 2/3 |
| 7 | **Nostr room** (Trystero, 5 of >= 7 pinned relays) | $0 | relay rate limits, kind allow-lists, churn (about 5 default-list changes in 20 months) | none | yes, 11/12 relays passed | no SLA; relays may reject ephemeral kinds (purplepag.es) or require payment (nostr.wine) | always, as the independent second plane for the chain room |
| 8 | MQTT public brokers | $0 | "testing" terms; two of four hostnames on mainstream DNS lists | none | yes | blocked at DNS level for HaGeZi users; topics world-readable | optional third fallback only |
| 9 | **Web seed only** (`ws=` + `xs=`, no peers) | static-host egress only | host egress, first-byte latency of the static host | none | the static host itself | loses P2P benefits and the chain's peer path | the floor: the site must always load this way; E_NO_PEERS must never fire when `xs=` works |

**Recommended configuration for magnet-web v1:** `tr=` list = [own row-2 or row-6 tracker on a neutral hostname] + [own second tracker on a different provider, optional] + `tracker.webtorrent.dev` + `tracker.openwebtorrent.com` + `tracker.novage.com.ua` (+ `open.ftorrent.com`), identical for every peer; `ws=` and `xs=` always present; chain-room discovery on Nostr; no MQTT by default.
